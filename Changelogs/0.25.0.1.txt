Update 0.25.0.1: The Cities of Soot and Ash

Added 2 new biomes, the Abandoned Village and the Sanctuary
Added a new pre-hardmode boss, the Excavator
Added a new mini-structure that can be found in the sky
Added 249 new items, 28 creatures, and 170 tiles/walls
Added alternative OST for The Advisor, Putrid Pinky, Pyramid, and the Planetarium, as well as songs for the new biomes
Many adjustments to existing content
Many bug fixes

The following lists are not exhaustive, as they do not contain information on many new items, which you'll have to discover for yourself!

Additions:
1. Added all remaining conduit variants and all remaining elemental plating furniture sets
2. Added Bestiary Entries for all NPCs that were missing them
3. Added trophies for all bosses, as well as mastermode drops for Lux and Advisor
4. Elemental Amulet now has 16 more variants
5. Added two new secret variant items 
6. Added a way to convert secret variant items back to their original variants
7. Added new critters to catch
8. Added some new recipes for vanilla items using SOTS ingredients, such as the Pocket Mirror
9. Added some unique shimmer recipes, such as Electromagnetic Lure -> D.E.F.E.
